# Independent source population expansion v1

Goal: collect distributions and document-level uncertainty, not count correlated token/head/step rows as samples.

512 source units: 256 WikiText article titles from one pinned Wikitext-103-raw training parquet shard, 256 conservative Python repository-name families from the pinned CodeParrot clean validation shard. Deterministic source-unit hash ranks; one eligible natural window per unit. Inputs frozen before any GPU outcome. Content hashes and token-5gram Jaccard >=0.8 exclude duplicates among selected windows. Upstream project lineage and related Wikipedia topics can remain correlated; no claim of global representativeness.

Qwen2.5-1.5B-Instruct frozen revision. Matched L512/L2048 contexts end at the same source location and share the natural nine-token continuation. Eight teacher-forced decode steps. BF16 1024 conditions; prespecified 64-source FP32 audit adds 128. Independent n remains 512. 128 exploratory and 128 confirmatory units per domain.

Six core variants: original passthrough, unquantized eager replay, K-only INT4 g32, V-only INT4 g32, both, packed/unpacked both. Each runs isolated and recurrent on cloned native cache. Exact no-op, unchanged snapshot and first-step history checks inherited from the frozen controlled ablation. Full native recomputation and dense fidelity recorded separately. This is dense-resident decode intervention, not a packed-resident cache implementation or full benchmark. FP32 audit is a paired numerical sensitivity analysis; it does not double independent n.

Primary endpoint: per-document mean relative logit L2 over eight steps; K-only minus V-only, L2048 BF16 confirmatory split, separately prose/code and isolated/recurrent (four prespecified contrasts). 5000 bootstrap resamples of document blocks; 98.75% pointwise percentile intervals give nominal Bonferroni family confidence of 95%, with bootstrap approximation limits. No guaranteed power. Secondary paired length/history, NLL, KL and top1 comparisons are exploratory. Report failures and valid paired n. Means, medians, q05/q95 and ECDF; no reliable q99 claim. NLL on eight targets is not corpus perplexity.

One sequential GPU worker, model reused in eight-condition batches, own shared lock, max allocated HBM96GiB, reserve HBM12GiB+minimum free32GiB, disk reserve24GiB. Campaign cap8h, batch cap40min. No-op control failure stops collection. Each condition sealed with hashes; raw logits retained only first prespecified source per domain (both lengths/dtypes), other conditions retain exact frozen input IDs and metric rows. Model and datasets pinned, raw source text not republished. Server-only files; no Git push. Every 128 conditions and final completion produce CPU statistics, ECDF, archive and hash.

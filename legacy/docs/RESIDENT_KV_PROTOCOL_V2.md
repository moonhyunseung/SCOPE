# Actual resident-KV protocol v2

This is a separate, gated H200 engineering experiment. It uses Qwen2.5-1.5B-Instruct at the pinned cached revision and BF16, with real screening prose/code prefixes. Confirmation sources are forbidden for hardware tuning. All paths execute the whole model for four natural teacher-forced decode tokens. Prefill and initial cache materialization are outside the decode interval; cache materialization is reported separately. There is no serving scheduler or heterogeneous workload claim.

The paths are native DynamicLayer eager, paged dense static eager, paged dense static SDPA, actual persistent INT4 with global dense reconstruction, actual persistent INT4 with bounded original eager attention, and a candidate Triton split packed-attention path. The candidate is ordinary split reduction; no Tensor Core, WGMMA, TMA, or theoretical throughput claim is made. SDPA backend choice is not assumed. Its full-model output must also pass the gate.

Each batch physically allocates distinct storage for copies of one real prefix. There is no expanded zero-stride KV storage, prefix sharing, repeated synthetic token extension or independent-source interpretation of batch size. Static caches use 128-token pages and reserve eight append slots. Valid token count and physical page padding are reported separately. Packed layers retain only uint8 codes and FP32 scales; transient dense reconstruction belongs to peak workspace, not resident cache storage. The independent CPU code/scale test checks the original frozen quantizer.

For each point a fresh same-representation reference executes all layers through original eager attention, using bounded batch chunks for packed caches. Four complete vocabulary logit vectors are held on the host. Each candidate request and step must be finite and have relative L2 <= **0.025** against this reference. A failing point remains GATE_D_FAIL with no accepted timing result. This gate measures execution fidelity to the quantized representation; it does not claim INT4 quality parity with unquantized outputs. The separate factorial campaign measures quantization effects.

Passing paths have two warmups and ten timed whole-model repetitions using CUDA events and host wall time. Cache length resets outside the interval. Projection, attention, cache append/encode, reconstruction or packed attention, and LM head are included in each repetition. Initial prefix prefill, cache materialization, host correctness validation, compilation and scheduler costs are excluded. Repetition variance is timing repeatability, not independent workload variation.

Per-point accounting includes all layer/head KV storages, model parameter/buffer unique storages, valid/padded storage bytes, actual allocator allocated/reserved/peaks, active requested/block rounding, inactive splits, reserved-minus-active bytes and physical HBM use. Physical-minus-allocator-reserved is an operational residual, not an exact attribution. Host allocator metadata is unknown. Workspace-and-growth is a peak upper bound. No raw allocator addresses or traces are public.

The pilot is L512,B1 for six methods. The later fixed grid is L512 at B1,16,256 and L1536 at B1,16,256,1024,2048,4096,6144, plus code L1536 at B1,4. These are planned grid points, not demonstrated capacities. The guard retains budget skips when conservative payload plus workspace estimates exceed a 96GiB allocator budget or 44GiB physical reserve. Actual OOM is retained and stops the controller. A measured frontier is feasible points only, never an inferred maximum. Large host logit reference buffers must fit a bounded fraction of available host memory.

The controller waits on the existing task GPU lock and uses bounded subprocesses. It never stops other GPU users, services or containers. It seals each terminal point and queues compact publication PENDING until remote verification. A failed implementation stops for bounded diagnosis; there is no automatic tolerance relaxation or silent replacement of failed attempts. This module is experimental until its actual H200 pilot is recorded.
